# 定时关机助手

一个**轻量、免安装、零依赖**的 Windows 定时电源管理工具。用系统自带的 .NET Framework 编写，单文件即可运行，支持多组定时计划，到点弹出**环形倒计时询问窗口**，可关机、重启、注销或睡眠。

## 功能特性

- 🕙 **多组定时计划**：可同时创建多个计划，互不影响
- 📅 **两种触发方式**：
  - 按**星期**循环（如周一~周四、周日，可任意多选）
  - 按**年月日**执行一次（指定日期，过期自动不安装）
- ⏳ **环形倒计时询问**：到点弹出深色窗口，中央进度环由蓝渐变为红，数字实时跳动
  - 等待秒数可自定义（默认 30 秒）
  - 最后 5 秒闪红提醒
  - 超时自动执行，无需守在电脑前
- 🔌 **多种电源操作**：关机 / 重启 / 注销 / 睡眠
- 🔍 **自动识别相关任务**：一键扫描电脑中其他关机/电源任务、开机自启项、孤立任务，按风险等级标色，可直接禁用/启用/删除
  - 自动保护 `\Microsoft\` 下的 Windows 系统任务
- 🗂️ **配置自动保存**：JSON 格式，随程序同目录，方便备份
- 🪟 **无黑框弹窗**：通过 Windows 任务计划程序静默触发，不闪命令行窗口

## 快速开始

1. 直接下载仓库内最新成品 [`latest/ShutdownHelper-latest.zip`](latest/ShutdownHelper-latest.zip)（仓库内始终是最新版，更新时直接覆盖）；也可在 [Releases](../../releases) 下载正式发布版本
2. 解压后双击 `ShutdownHelper.exe`
3. 在左侧选择计划，右侧修改时间、星期/日期、等待秒数
4. 点 **「应用修改」** 或 **「安装全部计划」** 即可
5. 关闭软件后，到点依然会自动触发

> 首次运行会自动在同目录生成 `config.json` 配置文件，无需手动创建。

## 快捷操作说明

| 按钮 | 作用 |
|------|------|
| 立即执行 | 立刻按当前计划执行一次 |
| 预览询问窗口 | 先看弹窗效果（不会真正执行电源操作） |
| 扫描相关任务 | 自动识别电脑中其他关机/电源任务 |
| 全部禁用 | 停用所有计划并清除系统任务 |

## 命令行参数

| 参数 | 说明 |
|------|------|
| （无参数） | 打开主管理窗口 |
| `-run <id>` | 触发指定编号的计划（由任务计划程序调用） |
| `-preview <id>` | 预览该计划的倒计时窗口（不执行任何电源操作） |

## 自行编译

本项目为**单文件源码**，无需安装 Visual Studio，使用系统自带的 C# 编译器即可：

```powershell
# 双击或在 PowerShell 中运行一键编译脚本
.\compile.ps1
```

编译后会在同目录生成 `ShutdownHelper.exe`。

## 关于安全软件误报

由于本程序会调用系统关机 API 并写入任务计划，个别杀毒软件可能出现**启发式误报**（机器学习特征）。

- 已通过 Windows Defender 官方扫描：`found no threats`
- 全部源码开源，可自行审查或编译
- 如被拦截，可在安全软件中添加信任；详见随包的《信任与误报说明.txt》

## 系统要求

- Windows 7 及以上（Windows 10 / 11 推荐）
- .NET Framework 4.x（系统一般自带）
- 电脑彻底关机状态下到点无法触发（系统机制限制）；睡眠/休眠会被唤醒执行
